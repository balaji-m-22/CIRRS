# CIRRS

Civic/Community Issue Reporting \& Routing System

## Problem Statement

Citizens report civic issues such as road damage, waste accumulation, drainage problems, streetlight failures, and other public infrastructure problems. CIRRS provides a structured workflow where citizens can submit issues with photos and location information, while municipal staff can review, assign, update, and resolve reported issues.

The system is based on the project requirements developed by Team Runtime Terror.
